# Welcome to QuickRecall's Storybook

QuickRecall is a personal full-stack developer interview-prep knowledge base. It covers JavaScript, TypeScript, React, Next.js, Redux, HTML/CSS, Node.js, and databases through notes, quick-recall cheat sheets, flashcards, and machine-coding problems with a side-by-side live demo and code viewer.

This Storybook is the workspace for its UI components. Storybook runs separately from the app, so stories are written, viewed, and tested here without touching the app's routes.

## Running Storybook

```bash
pnpm storybook          # start the dev server on http://localhost:6006
pnpm build-storybook    # static build to storybook-static/
```

The app is dark-mode only. The global preview decorator in `.storybook/preview.tsx` imports `src/app/globals.css` and wraps every story in a `.dark` container on the app's real background, so components render exactly as they do in the app. No per-story setup is needed.

## Writing stories

Stories are colocated next to their component as `*.stories.tsx`, for example `src/components/ui/avatar.stories.tsx`. The framework is `@storybook/nextjs-vite`, so the `@/` path alias and Tailwind classes work out of the box.

Each story set uses the standard `Meta` and `StoryObj` exports:

```tsx
import type { Meta, StoryObj } from '@storybook/nextjs-vite'
import { Button } from './button'

const meta = {
  component: Button,
  tags: ['autodocs']
} satisfies Meta<typeof Button>

export default meta
type Story = StoryObj<typeof meta>

export const Default: Story = {
  args: { children: 'Button' }
}
```

The `@storybook/addon-docs` Autodocs entry is generated from the component's props when a story set carries the `autodocs` tag.

## Testing stories

Stories double as tests. `@storybook/addon-vitest` is wired into `vitest.config.ts` as a second `storybook` project, so `pnpm test` runs every story in a real browser (Playwright, Chromium) alongside the existing node unit tests. Interactions in `play` functions are executed and asserted during that run.

## Addons

The following addons are enabled in `.storybook/main.ts`:

| Addon | Purpose |
| --- | --- |
| `@storybook/addon-docs` | Autodocs and MDX documentation |
| `@storybook/addon-a11y` | Accessibility checks, surfaced as test todos |
| `@storybook/addon-vitest` | Runs stories as browser tests via Vitest |
| `@chromatic-com/storybook` | Chromatic integration for visual review |
| `@storybook/addon-mcp` | MCP server at `/mcp` for agent-driven story authoring |

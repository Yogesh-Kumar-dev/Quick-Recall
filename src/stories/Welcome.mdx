## About QuickRecall

QuickRecall is a personal interview preparation platform built to help developers strengthen their understanding through active recall rather than memorization.

Beyond interview questions, the platform focuses on helping users understand the reasoning behind concepts with explanations, quizzes, and interactive learning experiences.

---

## Why Storybook?

As the application grows, maintaining a consistent user experience becomes increasingly important.

This Storybook serves as the component library for QuickRecall. Components are built, reviewed, documented, and tested in isolation before being integrated into the application. This approach makes it easier to iterate on the UI, catch regressions early, and maintain consistency across the product.

---

## Foundations

QuickRecall's components are built on top of excellent open-source projects:

- **shadcn/ui** for accessible, copy-and-own UI primitives
- **MongoDB LeafyGreen** for selected components such as Callout and Code
- **Storybook** for documenting and validating the application's reusable components

This Storybook focuses on how these building blocks are composed and customized for QuickRecall rather than documenting the underlying libraries themselves.

---

## Technology stack

The component library is built with:

- **Storybook** for isolated component development and documentation
- **shadcn/ui** as the primary component foundation
- **Tailwind CSS v4** for styling
- **MongoDB LeafyGreen** components where they best fit the user experience
- **Vitest + Playwright** for component interaction testing

---

## Development workflow

Building components independently before integrating them into the application helps:

- Keep the interface consistent
- Improve maintainability
- Simplify debugging
- Reduce unintended regressions
- Encourage reusable UI patterns

As QuickRecall evolves, this Storybook grows alongside it, providing a single place to develop, review, and document the application's UI.
